# ユビキタス言語定義 (glossary.md)

IR Watch のドメイン用語・ビジネス用語・UI/UX 用語を定義する。新しい用語を追加する場合は、実装より先にこのファイルへ追記する。

## ドメイン用語

| 日本語 | 英語 / コード上の名前 | 定義 |
| --- | --- | --- |
| 適時開示 | Disclosure | TDnet を通じて上場企業が公表する開示文書。`src/lib/tdnet.ts` の `Disclosure` 型。 |
| 監視銘柄 | WatchedCompany | 利用者がこの端末で開示を追跡する対象として登録した銘柄。`src/lib/watchlist.ts` の `WatchedCompany` 型。 |
| 証券コード | code | TSE の銘柄コード。4桁の数字、または JPX の新形式(英字を含む4桁)。`normalizeCode()` で正規化する。 |
| 自社株買い / 自己株式取得 | Treasury stock buyback | 会社が自社の株式を市場等から買い戻すこと。`isTreasuryStockDisclosure()` で開示タイトルから判定する。 |
| スナップショット | Snapshot | GitHub Actions が定期的に取得し `public/*.json` に書き出す、ある時点のデータのコピー。ブラウザは常にこのスナップショットを読む(TDnet 本体・ミラー API に直接アクセスしない)。 |
| 時価総額 | Market cap / marketCapOku | ある銘柄の発行済株式数×株価で計算される企業価値。本アプリでは億円単位 (`*Oku` サフィックス) で扱う。 |
| 販売個数 | Sales volume / volumeChangeRatePercent | 手数料の量・サービス提供数・ライセンス数など、企業が販売する「数量」側の指標。時価総額予測の入力の一つ。 |
| 販売単価 | Unit price / priceChangeRatePercent | 手数料単価・サービス単価・ライセンス単価など、企業が販売する「単価」側の指標。時価総額予測の入力の一つ。 |
| 増収率 | Revenue change rate | 販売個数の増減率と販売単価の増減率から導かれる、売上の増減率。`(1+個数変化率)×(1+単価変化率)-1` で計算する。 |
| 次の四半期 | Next quarter | 直近の増収率が1四半期分だけ反映された時点の予測。 |
| 次の決算(本決算) | Next full-year earnings | 直近の増収率が、決算までの残り四半期数だけ複利で反映された時点の予測。 |
| 予測時価総額 | Forecast market cap | 上記の増収率をもとに算出する、将来時点の時価総額の見込み値。 |

## ビジネス用語

| 日本語 | 定義 |
| --- | --- |
| TDnet | 東京証券取引所の適時開示情報閲覧サービス(Timely Disclosure network)。本アプリの一次情報源。 |
| Yanoshin ミラー API | TDnet に公式 API が無いため利用している、コミュニティ運営の JSON ミラー。 |
| GitHub Pages | 本アプリのホスティング先。静的サイトのみを配信できる(サーバーサイド処理は不可)。 |

## UI/UX 用語

| 日本語 (画面表示) | 意味 |
| --- | --- |
| 監視銘柄 | 「監視銘柄」タブ。登録銘柄の開示一覧を表示する。 |
| 自社株買い(全銘柄) | 「自社株買い」タブ。全上場企業の自己株式取得状況の集計表を表示する。 |
| 時価総額予測 | 「時価総額予測」タブ。登録銘柄について、販売個数・販売単価の増減シナリオから将来の時価総額を試算する。 |
| NEW | 前回表示以降に新しく取り込まれた開示情報につくラベル。 |

## 命名規則

* コード上の識別子は英語・キャメルケース(型は PascalCase)を用いる。日本語の画面文言とは `glossary.md` の対応表で対応させる。
* localStorage のキーは `ir-watch:<用途>` のプレフィックスを付ける(例: `ir-watch:companies`, `ir-watch:market-cap-forecast`)。
* 金額は円単位の `number`(`*Yen` サフィックス)、または億円単位の `number`(`*Oku` サフィックス)で保持し、両者を混在させない。
