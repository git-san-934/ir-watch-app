# プロダクト要求定義書 (product-requirements.md)

## プロダクトビジョンと目的

IR Watch は、東証(TSE)上場企業の適時開示・自己株式取得状況を、登録不要・サーバーレスで手軽に確認できる Web アプリである。今回追加する「時価総額予測」機能は、その延長として、監視銘柄について「販売個数(取扱量・サービス提供数・ライセンス数など)」と「販売単価」の増減シナリオを入力すると、次の四半期時点・次の本決算時点の見込み時価総額を試算できるようにする。

## ターゲットユーザーと課題・ニーズ

* 個人投資家で、複数の東証上場企業の IR を自分でウォッチしている人
* 課題: 各社の IR ページを個別に巡回する手間、決算のインパクトを大まかにでも事前に見積もる手段がないこと
* ニーズ: 「販売数量が増えたら/減ったら」「単価が上がったら/下がったら」時価総額がどの程度動きそうか、単純化されたシナリオで素早く試算したい

## 主要な機能一覧

1. 監視銘柄の登録・削除、開示情報の一覧表示(既存)
2. 自社株買い(全銘柄)集計表示(既存)
3. **時価総額予測(今回追加)**
   * 監視銘柄ごとに、現在の時価総額(億円)を入力
   * 販売個数の増減率(%)、販売単価の増減率(%)を入力(正負どちらも可 = 増加・減少の両方を1つの数値で表現)
   * 決算までの残り四半期数を入力(既定4)
   * 上記から「次の四半期時点」「次の本決算時点」の見込み時価総額を自動計算して表示

## 成功の定義

* 監視銘柄に対して時価総額と増減率を入力すれば、次の四半期・次の本決算時点の見込み時価総額が即座に(サーバー通信なしで)表示される
* 入力値はブラウザに保存され、再訪問時も保持される
* 既存機能(監視銘柄・自社株買い集計)を壊さない

## ビジネス要件

* 追加費用が発生しない構成であること(サーバー・DB・有料 API を新設しない)
* 静的サイト(GitHub Pages, `next build --output export`)としてデプロイ可能であること

## ユーザーストーリー

* 監視銘柄の投資家として、対象企業の現在の時価総額を登録したい。そうすれば予測の基準値として使える。
* 監視銘柄の投資家として、販売個数と販売単価それぞれの増減率を入力したい。そうすれば「量が増えた場合」「単価が下がった場合」など様々なシナリオを試せる。
* 監視銘柄の投資家として、次の四半期と次の本決算、両方の時点の見込み時価総額を見たい。そうすれば短期・中期の影響の違いを把握できる。

## 受け入れ条件

* 「時価総額予測」タブが追加され、監視銘柄ごとに現在の時価総額・販売個数変化率・販売単価変化率・残り四半期数を入力できる
* 入力すると、次の四半期時点・次の本決算時点の見込み時価総額(億円、現在比の増減率つき)が表示される
* 監視銘柄が0件の場合は、その旨を案内するメッセージを表示する
* 入力値はブラウザの localStorage に保存され、ページ再読み込み後も復元される
* 既存の監視銘柄タブ・自社株買いタブの挙動に影響を与えない

## 機能要件

* FR-1: 監視銘柄ごとに現在の時価総額(億円)を保存・編集できる
* FR-2: 監視銘柄ごとに販売個数変化率(%)・販売単価変化率(%)・残り四半期数を保存・編集できる
* FR-3: 増収率 = (1+個数変化率)×(1+単価変化率)-1 を計算する
* FR-4: 次の四半期時点の見込み時価総額 = 現在の時価総額 ×(1+増収率)を計算する
* FR-5: 次の本決算時点の見込み時価総額 = 現在の時価総額 ×(1+増収率)^残り四半期数 を計算する
* FR-6: 上記の計算はすべてクライアント側(ブラウザ内)で完結し、外部通信を必要としない

## 非機能要件

* NFR-1: 追加機能はサーバー・DB を必要としない(静的サイトのまま)
* NFR-2: 個人が入力した時価総額・増減率はこの端末の localStorage にのみ保存し、外部送信しない(既存機能と同じプライバシー方針)
* NFR-3: 実際の株価・時価総額データを外部 API から自動取得する仕組みは今回のスコープに含めない(下記「今回のスコープ外・既知の制約」参照)。将来的に信頼できるデータ源が確認できた場合の拡張ポイントとして設計する

## 今回のスコープ外・既知の制約

* 本機能の予測は、AI による自然文的な将来予測ではなく、利用者が入力した増減率を単純な数式(売上比例モデル)に当てはめた**透明で説明可能な試算**である。マルチプル(PER 等)の変動、競合・市況などの他要因は考慮しない。UI 上も「簡易試算」であることを明記する
* 現在の時価総額は外部データソースからの自動取得を行わず、利用者が手入力する(TDnet ミラー API 同様、無料で商用利用可能な時価総額 API がこの環境から検証できなかったため)。将来 `scripts/fetch-tdnet.ts` と同様のサーバーサイド取得スクリプトを追加し、`public/*.json` 経由で自動反映することを拡張候補とする
