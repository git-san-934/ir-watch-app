# 要求内容: 時価総額予測タブの追加

## 変更・追加する機能の説明

監視銘柄タブ・自社株買いタブに加え、新しく「時価総額予測」タブを追加する。監視銘柄ごとに以下を入力できるようにする。

* 現在の時価総額(億円)
* 販売個数(手数料の量・サービス提供数・ライセンス数など)の増減率(%)。正の値=増加、負の値=減少
* 販売単価(手数料単価・サービス単価・ライセンス単価など)の増減率(%)。正の値=増加、負の値=減少
* 本決算までの残り四半期数(既定4)

これらの入力から、次の四半期時点・次の本決算時点の見込み時価総額を自動計算し、現在比の増減率とともに表示する。

## ユーザーストーリー

* 監視銘柄の投資家として、対象企業の現在の時価総額を登録したい。そうすれば予測の基準値として使える。
* 監視銘柄の投資家として、販売個数と販売単価それぞれの増減率を独立して入力したい。そうすれば「量が増えて単価が下がる」のような複合シナリオも試せる。
* 監視銘柄の投資家として、次の四半期と次の本決算、両方の見込み時価総額を見たい。そうすれば短期的な影響と、その傾向が続いた場合の中期的な影響の違いを把握できる。

## 受け入れ条件

* 「時価総額予測」タブが追加され、監視銘柄がある場合はカードごとに入力フォームと計算結果が表示される
* 監視銘柄が0件の場合、その旨を案内するメッセージが表示される(既存タブの空状態と同じトーン)
* 現在の時価総額が未入力の場合、計算結果ではなく入力を促すメッセージを表示する
* 入力するたびに(サーバー通信なしで)即座に計算結果が更新される
* 入力値は監視銘柄の id に紐づけて localStorage に保存され、リロード後も復元される
* 監視銘柄を削除すると、対応する予測入力値も削除される
* 既存の「監視銘柄」「自社株買い(全銘柄)」タブの挙動・データに影響を与えない
* `npm test` / `npm run lint` / `npx tsc --noEmit` / `npm run build` がすべて成功する

## 制約事項

* 外部の時価総額データ API を新規に呼び出さない(`docs/product-requirements.md` の既知の制約を参照)。現在の時価総額は利用者の手入力とする
* サーバー・DB を新設しない。すべてクライアント側(ブラウザ)で完結させる
* 既存の `WatchedCompany` 型・`watchlist.ts` の既存 API は変更しない(後方互換を保つ)
